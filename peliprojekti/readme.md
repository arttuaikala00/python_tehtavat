# Jamin tappo peli

## Pelin idea
Jamin tappo pelissä tutkitaan luolaa, kerätään resursseja, valmistetaan varusteita ja tarvikkeita, taistellaan örkkien kanssa ja etsitään aarteita. Pelin tavoite on valmistauta ja tappaa päävihollinen Jami, joka odottaa luolan kellarissa.

## Pelin toimintaperiaate
Pelin toiminta perustuu valikkoihin, jossa pelaaja päättää haluamansa toiminnon. Luola on 5x5 matriisi, joka koostuu 3x3 matriiseista, eli huoneista.
